# Estudos de JavaScript

Esta pasta guarda o plano de estudo do Matheus. Tudo em português, exceto as chaves que o Tutor lê (Goal, Source, Help, Plan, Rules, Misconceptions).

## Regras permanentes
- Não escrever código pronto para o Matheus. Ele escreve o código dele; eu pergunto e corrijo.
- IA só para dúvidas de conceito. Fórum e documentação oficial são permitidos.
- Explicar o porquê de um conceito antes de praticar.
- Respostas diretas, em português.

## Onde está o progresso
- Plano geral: Objetivos/learning-goals.md
- Etapa atual: pasta "Etapa 1 - JavaScript", partes 1a a 1d, nessa ordem.
- Progresso das lições: goal.md de cada parte (o Tutor atualiza).
- Histórico de sessões: Objetivos/learning-log.md.

## Ao iniciar uma sessão
1. Ler este arquivo, Objetivos/learning-goals.md e Objetivos/learning-log.md.
2. Dizer em uma linha onde paramos e qual é a próxima lição.
3. Só então seguir com o Tutor.

## Ao encerrar (quando eu disser "encerrar")
Registrar no Objetivos/learning-log.md: data, lições feitas, respostas pendentes, equívocos e próxima lição.
