Seu palpite

Da última vez: o que console.log(triplo(4)) mostra, com const triplo = (n) => n * 3? Você disse 12. É a c) 12.

  • a) undefined: acha que sem a palavra return nada volta. Na forma sem chaves, o valor volta sozinho.
  • b) [Function: triplo]: confunde a função com a chamada. triplo(4) tem parênteses, então roda.
  • c) 12: n recebe 4, e a expressão n * 3 é devolvida.
  • d) erro de sintaxe: => é uma forma válida de escrever uma função.

A ideia

Uma função como triplo faz um cálculo só, mas ocupa três linhas. Na lição 04, você vai passar funções pequenas como esta para outras funções. Por isso vale ter uma forma curta. A arrow function é essa forma (MDN, "Arrow functions").

Ela tem dois tipos de corpo (MDN, "Arrow functions", "Function body"):

  • Sem chaves: o corpo é uma única expressão, e o valor dela volta sozinho, sem return.
  • Com chaves: o corpo funciona como o de uma função comum. Ele aceita várias linhas, e o valor só volta com return. Sem return, a função devolve undefined.

A forma sem chaves só serve quando a função devolve uma expressão direto. Se o corpo tem instruções, como const ou if, as chaves são obrigatórias.
