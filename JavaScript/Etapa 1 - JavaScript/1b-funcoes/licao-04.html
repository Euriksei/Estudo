Seu palpite

Da última vez, o palpite ficou sem resposta. A pergunta era: o que repetir(3, (n) => console.log("volta " + n)) mostra? É a b) volta 1, volta 2 e volta 3.

  • a) nada: a arrow é criada, mas o repetir chama ela com acao(i), uma vez por volta.
  • b) volta 1, volta 2 e volta 3: o parâmetro acao recebe a arrow, e o loop chama ela com 1, 2 e 3.
  • c) erro: acao é uma função, porque recebeu uma arrow.
  • d) [Function: acao]: isso apareceria com console.log(acao), sem chamar.

A ideia

O repetir sabe fazer o loop, mas não sabe o que fazer em cada volta. Se cada ação precisasse de um loop novo, você escreveria o mesmo for várias vezes. A solução é passar a ação como parâmetro.

Na lição 02, você viu que somar, sem parênteses, é a própria função, guardada como valor. Um valor pode ir para outra função como argumento. Uma função passada assim se chama callback: a função de fora recebe a callback e chama ela por dentro, com os argumentos certos (MDN, glossário, "Callback function"). Quem chama a callback é a função de fora, não você.

Exemplo resolvido

function repetir(vezes, acao) {
  for (let i = 1; i <= vezes; i++) {
    acao(i)
  }
}
const mostrar = (n) => console.log("volta " + n)
repetir(3, mostrar)
PassoO que aconteceu
1repetir(3, mostrar): vezes recebe 3, e acao recebe a função mostrar, sem rodar ela
2na primeira volta, acao(1) tem parênteses: agora mostrar roda com n = 1 e mostra volta 1
3as voltas 2 e 3 fazem o mesmo com 2 e 3
4para fazer outra coisa em cada volta, você troca só a callback. O repetir continua igual

Pergunta: o mostrar não tem return. Que valor ele devolve? Esse é o valor que o acao recebe. Teste no Node com o exemplo da lição e diga o que acontece na primeira volta do loop (MDN, glossário, "Callback function").




Como mostrar() não retorna uma função, o valor passado para acao será undefined. Então, quando o loop tentar executar acao(1), ocorrerá um erro, pois estamos tentando chamar undefined como se fosse uma função.


Certo. O acao recebe undefined, e acao(1) dá TypeError: acao is not a function. Antes disso, aparece volta undefined, porque o mostrar() rodou uma vez na chamada (MDN, glossário, "Callback function").
