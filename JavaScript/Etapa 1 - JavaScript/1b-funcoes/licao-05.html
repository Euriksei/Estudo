Questions

Q1. O repetir da lição 04, com outra callback. Qual número aparece?

function repetir(vezes, acao) {
  for (let i = 1; i <= vezes; i++) {
    acao(i)
  }
}
let total = 0
repetir(4, (n) => { total = total + n })
console.log(total)
10
Certo: 1 + 2 + 3 + 4 = 10. O repetir chama a callback com 1, 2, 3 e 4, e ela soma cada número no total.

Q2. O que aparece?

const formatar = (nome, p) => { "[P" + p + "] " + nome }
console.log(formatar("Estudar", 2))
  • a) [P2] Estudar
  • b) undefined
  • c) um erro de sintaxe
  • d) [Function: formatar]
B
Certo: com chaves, a arrow só devolve com return. Sem ele, devolve undefined (MDN, "Arrow functions", "Function body").

Q3. Com a checar(texto, validar) da lição 04, qual linha testa o texto "2" com a prioridadeValida do jeito certo?

  • a) checar("2", prioridadeValida("2"))
  • b) checar("2", prioridadeValida())
  • c) checar("2", prioridadeValida)
  • d) checar(prioridadeValida, "2")
A

Você escolheu a) checar("2", prioridadeValida("2")). Rodei com as suas funções do licao-04.js:

  • prioridadeValida("2") roda primeiro e devolve 2. Então o parâmetro validar recebe o número 2.
  • dentro da checar, validar(texto) vira 2("2"): TypeError: validar is not a function.

É o mesmo caso do mostrar() da lição 04. Pergunta: qual das quatro linhas manda para o validar a própria função, sem rodar ela? (MDN, glossário, "Callback function")

C
Certo: checar("2", prioridadeValida) manda a própria função, e a checar chama ela por dentro com validar(texto).

Q4. Qual número aparece?

function classificar(p) {
  if (p >= 3) { return "Alta" }
  if (p >= 2) { return "Media" }
  return "Baixa"
}
let alta = 0
for (const p of [3, 1, 2, 3]) {
  if (classificar(p) === "Alta") { alta++ }
}
console.log(alta)
2
Certo: só os dois 3 passam no primeiro if. O 2 devolve "Media", e o return encerra a função antes do "Baixa".

Q5. Qual número aparece?

const aplicar = (x, f) => f(x)
console.log(aplicar(5, (n) => n * 2) + aplicar(1, (n) => n + 10))
21
Certo: aplicar(5, ...) devolve 10, e aplicar(1, ...) devolve 11. Juntos dão 21.

Q6. O que aparece, nesta ordem?

function quadrado(n) {
  console.log(n * n)
}
const r = quadrado(3) + 1
console.log(r)
  • a) 9, depois 10
  • b) 10 só
  • c) NaN, depois 9
  • d) 9, depois NaN
9 e NaN porque não tem return
Certo: o console.log de dentro mostra 9. Sem return, quadrado(3) vale undefined, e undefined + 1 dá NaN. Essa é a regra do + da 1a.
