Onde você está

Variáveis, condições e repetição. Esta lição é um diagnóstico, não uma prova: ela mostra o que você já sabe, e assim as próximas lições pulam o que você domina e reforçam o que falta.

Por que começar assim

Quase todo programa faz três coisas: guarda valores (variáveis), escolhe um caminho (condições) e repete uma ação (loops). O gerenciador de tarefas também: guarda uma tarefa, decide se ela está concluída e percorre a lista de tarefas. Se você consegue prever o que um trecho faz antes de executá-lo, você entende o código, não está só decorando.

Regra desta lição: responda sem executar nada e sem pesquisar. Errar aqui é útil, porque mostra onde focar. Depois de responder, você pode conferir no console do navegador (F12 → Console) ou com node.

Parte A: preveja a saída

Variáveis

A1. O que aparece no console? Explique linha por linha.

let pontos = 10;
pontos = pontos + 5;
console.log(pontos);
DicaO sinal = não significa "é igual". Ele significa "guarde o valor da direita na variável da esquerda". A direita é calculada primeiro.
Variáveis

A2. E aqui, o que acontece? Por quê?

const nome = "Ana";
nome = "Bia";
console.log(nome);
DicaPense no que a palavra const promete sobre a variável.
Condições

A3. Qual mensagem aparece? E se idade fosse 18?

let idade = 17;
if (idade >= 18) {
  console.log("Pode entrar");
} else {
  console.log("Acesso negado");
}
DicaLeia >= em voz alta: "maior ou igual".
Repetição

A4. O que aparece no console, e quantas vezes o bloco roda?

for (let i = 0; i < 3; i++) {
  console.log(i);
}
DicaO for tem três partes separadas por ;: o começo, a condição para continuar e o que acontece ao fim de cada volta. Simule as voltas no papel.
