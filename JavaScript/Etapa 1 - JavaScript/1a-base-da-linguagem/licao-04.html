A ideia

O seu código da lição 03 tem um problema. Cada if separado é testado, mesmo depois que outro já deu certo. Muitas vezes você quer que só um caminho rode. O else if resolve isso. O JavaScript testa as condições de cima para baixo. A primeira condição verdadeira roda, e as outras são puladas. O else só roda se nenhuma condição deu certo (MDN, "Controle de fluxo", if...else).

O switch faz o mesmo para uma lista de valores. Ele compara com ===, então o tipo conta. Depois que um case combina, ele roda até achar um break. Sem o break, ele continua nos case de baixo (MDN, "Controle de fluxo", switch).

Exemplo resolvido

const prio = 3
if (prio === 1) {
  console.log("Baixa")
} else if (prio === 2) {
  console.log("Média")
} else if (prio === 3) {
  console.log("Alta")
} else {
  console.log("Inválida")
}
PassoTesteResultadoO que aconteceu
1prio === 1falsepula "Baixa"
2prio === 2falsepula "Média"
3prio === 3truemostra "Alta"
4else-não é testado: um caminho já rodou

O mesmo exemplo com switch:

switch (prio) {
  case 1: console.log("Baixa"); break
  case 2: console.log("Média"); break
  case 3: console.log("Alta"); break
  default: console.log("Inválida")
}

Um colega diz: "com dias = -2, aparece Atrasada". O que está errado nessa afirmação? Responda com as suas palavras.


Faça como na tabela do exemplo resolvido. Primeiro passo: com dias = -2, o teste dias < 7 dá true ou false? Depois olhe o passo 4 da tabela: o que acontece com os else if que vêm depois de um teste true? Se quiser, cole o código num arquivo e rode.


O erro está na ordem das condições. Como dias = -2, a primeira condição (dias < 7) já é verdadeira, então o código exibe "Esta semana" e não verifica as próximas condições. Para funcionar corretamente, a condição de atraso deve ser verificada antes das demais.


Certo. "a primeira condição (dias < 7) já é verdadeira" é o ponto central: só o primeiro caminho verdadeiro roda. Por isso a condição mais estreita (dias < 0) vem primeiro, e a mais larga (dias < 7) vem por último (MDN, "Controle de fluxo", if...else).
