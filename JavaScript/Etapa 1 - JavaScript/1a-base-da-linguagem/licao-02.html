Variáveis com let e const

Por que existem três formas de criar uma variável, e qual usar no seu código.

Por que isso importa

Na lição 01 você viu dois problemas reais: um const que recebeu outro valor (o programa quebrou) e um i sem let que vazou para fora do loop (o programa não quebrou, o que é pior). As palavras let, const e var existem para você dizer ao JavaScript duas coisas sobre cada variável:

  1. Ela pode receber outro valor depois? (reatribuição)
  2. Em que parte do código ela existe? (escopo)
Pode receber outro valor?Onde existe
constNãoSó no bloco { } onde foi criada
letSimSó no bloco { } onde foi criada
varSimNa função inteira (ignora blocos como if e for)

var é a forma antiga (de antes de 2015). let e const foram criados para corrigir os problemas dela. Você vai ver var em código antigo e em tutoriais, por isso precisa reconhecer, mas no seu código a regra de hoje é:

Use const por padrão. Troque para let só quando a variável precisar receber outro valor. Não use var.

O detalhe do const

Pense na variável como uma etiqueta colada em um valor. O const proíbe descolar a etiqueta e colar em outro valor (fazer nome = ... de novo). Ele não diz nada sobre o valor em si. Para números e textos isso não faz diferença, porque eles não mudam por dentro. Mas uma lista (array) pode mudar por dentro, ganhando ou perdendo itens. A pergunta A3 testa exatamente isso.

Você ainda não estudou arrays (isso é a parte 1c). Por enquanto basta saber: [1, 2] é uma lista com dois números, e lista.push(3) coloca o 3 no fim da lista.
