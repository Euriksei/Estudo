Tipos e operadores

Por que "concluido: " + true virou texto e undefined + 10 virou NaN.

Por que isso importa

Todo valor em JavaScript tem um tipo, e o tipo decide o que um operador faz com ele. O mesmo + soma dois números, mas junta dois textos. Quando os tipos se misturam, o JavaScript converte sozinho um deles, sem avisar. Isso se chama coerção, e é a origem do seu NaN.

No gerenciador de tarefas isso vai acontecer de verdade: tudo o que chega de um formulário ou de uma requisição chega como texto. Uma prioridade digitada como 3 chega como "3". Se você somar sem converter, o resultado sai errado e nenhum erro aparece.

Os tipos básicos

TipoExemplosPara quê
número (number)3, -1.5, NaNcontas
texto (string)"Tarefa_1", "3", ""nomes, mensagens
booleano (boolean)true, falsesim ou não
undefinedundefined"ainda não recebeu valor" (o JavaScript coloca sozinho)
nullnull"vazio de propósito" (você coloca)

Para descobrir o tipo de um valor, use typeof: escreva typeof, um espaço e o valor, dentro de um console.log. Ele devolve o nome do tipo como texto.

Os operadores

Aritméticos

+ - * / e % (resto da divisão: 7 % 2 é 1, porque 7 dividido por 2 dá 3 e sobra 1). Atenção: só o + também sabe juntar textos.

Comparação

> < >= <=, e as duas igualdades: == (converte os tipos antes de comparar) e === (compara valor e tipo, sem converter). O resultado é sempre um booleano.

Lógicos

&& (E: as duas coisas precisam ser verdadeiras), || (OU: basta uma) e ! (NÃO: inverte).

Conversão de propósito

Number(valor) tenta transformar em número. String(valor) transforma em texto. Converter você mesmo é melhor que deixar o JavaScript adivinhar.
