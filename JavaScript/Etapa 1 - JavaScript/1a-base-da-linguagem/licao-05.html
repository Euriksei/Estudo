Seu palpite

Da última vez: o que o while com i < 3 mostra? Você disse 3, e está certo: é a d) 3.

  • a) 0: acha que o loop nunca roda.
  • b) 2: para uma volta antes, como se o i não chegasse a 3.
  • c) 4: conta uma volta a mais, o mesmo erro da lição 01.
  • d) 3: o loop para quando i < 3 fica false, e isso acontece com i = 3.

A ideia

O menu da lição 04 pergunta uma vez só. Se a pessoa digita abc, o programa mostra o erro e acaba. Você quer perguntar de novo, até a resposta ser válida. Um loop faz isso: ele repete um bloco enquanto uma condição é verdadeira.

O while testa a condição antes de cada volta. Quando ela dá false, o loop acaba. O for junta três partes numa linha: início, condição e passo. O for...of passa por cada item de uma lista. Se nada dentro do loop muda a condição, ele nunca para (MDN, "Laços e iterações").

Exemplo resolvido

let i = 0
while (i < 3) {
  i = i + 1
}
console.log(i)
Voltai antesi < 3O que aconteceu
10truei vira 1
21truei vira 2
32truei vira 3
-3falsesai do loop e mostra 3

As mesmas três voltas com for, e um for...of numa lista:

for (let i = 0; i < 3; i++) {   // início; condição; passo
  console.log("volta " + i)        // volta 0, volta 1, volta 2
}

const tarefas = ["Comprar pão", "Estudar JS"]
for (const t of tarefas) {
  console.log(t)                   // Comprar pão, Estudar JS
}

Questions

Q1. Um colega diz: "for (let i = 1; i <= 5; i++) roda 4 vezes, porque 5 - 1 = 4". O que está errado nessa conta? Responda com as suas palavras.

esta errado porque a primeira ver que rodar vai imprimir o valor de i assim que o programa começa, ou seja, 1
Certo na ideia: a primeira volta já usa i = 1, e ela conta. Faltou o número final. As voltas são 1, 2, 3, 4 e 5, então são 5. A conta 5 - 1 = 4 conta os espaços entre os números, não os números. Com <=, some 1: 5 - 1 + 1 = 5 (MDN, "Laços e iterações", for).

Q2. No licao-05.js, use um while para perguntar a prioridade com prompt até a pessoa digitar um número inteiro de 1 a 3. Cada resposta errada mostra Prioridade inválida, tente de novo. No fim, mostre Prioridade: 2 (com o número digitado). Teste digitando, em sequência, abc, 5, 2.5 e 2, e mande a saída completa.

Feito

Certo. Rodei o licao-05.js com as entradas abc, 5, 2.5 e 2. As três primeiras mostram Prioridade inválida, tente de novo, e a última mostra Prioridade: 2. Também testei a entrada vazia, 0 e 3, e deu certo.

Você usou do...while, que roda o bloco antes do primeiro teste. É a escolha certa aqui: a pergunta precisa ser feita pelo menos uma vez (MDN, "Laços e iterações", do...while). Um detalhe: a mesma condição aparece duas vezes. Se você mudar uma e esquecer a outra, o código quebra.

Q3. Quais números este código mostra, em ordem? Preveja antes de rodar.

for (let i = 10; i > 0; i = i - 3) {
  console.log(i)
}
10, 7 ,4 ,1
Certo. Depois do 1, o i vira -2, e -2 > 0 dá false.

Você agora sabe repetir um bloco com while, do...while, for e for...of, contar quantas voltas um loop dá, e pedir uma entrada até ela ser válida.
