# Metas de aprendizado

## Meta de longo prazo

- Desenvolver aplicações web completas com JavaScript, Node.js, Express e API REST, dominando JavaScript nas atividades propostas e sabendo explicar os conceitos, as ferramentas e cada linha que escrevo.

## Projeto atual: gerenciador de tarefas

- Objetivo: um sistema com API REST, interface web e banco SQLite, construído sem IA para gerar código.
- Prazo: 1 a 2 semanas, a partir de 23/10/2026.
- Ritmo: 2 a 3 horas por dia.
- Código do projeto: pasta `Gerenciador de Tarefas/`, dentro de `Programming`.
- Regras: IA só para tirar dúvidas de conceito. Fórum e documentação oficial são permitidos. Nada de copiar código.
- Receber alguns problemas para resolver, para fixar os conceitos

## Etapas

Cada etapa tem um critério de conclusão. Só a etapa atual tem lições e checklist detalhados.

- [ ] **Etapa 1: JavaScript essencial.** Critério: escrevo de cabeça funções que transformam listas de objetos e faço `fetch` com `async/await`.
- [ ] **Etapa 2: Frontend com HTML, CSS e DOM.** Critério: monto uma tela que lista e cria itens, sem usar exemplo pronto.
- [ ] **Etapa 3: Node.js e Express.** Critério: sirvo rotas GET e POST e testo as respostas.
- [ ] **Etapa 4: API REST.** Critério: CRUD completo, com status HTTP corretos e validação de dados.
- [ ] **Etapa 5: SQLite.** Critério: os dados continuam lá depois de reiniciar o servidor.
